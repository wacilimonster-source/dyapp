# 道渊 0.9.0

> 安卓手机 / 平板。主题：**下得下来、看得过来、回得去**。

## 重要变更

- **不再提供 Windows 桌面版**。本版起只发布安卓 APK；Release 里不再有 `-windows-x64-setup.exe`。已装 Windows 版的用户不会收到后续更新。

## 修复

- **应用内更新在国内下载失败**：旧版只直连 `github.com`，国内常连不上，一直等到超时才报错。现在按「`ghfast.top` → `gh-proxy.com` → GitHub 直连」逐个尝试，连接 8 秒、连上后 20 秒无数据就换下一个来源，全部失败才报错并列出每个来源的原因。
  - 走镜像时**强制 SHA-256 校验**：下载中边写盘边算哈希，与 GitHub 返回的资产 `digest` 比对，不一致就丢弃并换下一个来源。没有哈希时不会启用镜像，只走直连。
  - 检查更新同样在直连 `api.github.com` 失败（超时 / 5xx / 429）后回退到 `gh-proxy.com`。
  - 下载完成后会显示「已通过 SHA-256 校验，来源 xxx」。
- **绝色榜排名显示成「第 第九 位」**：数据里已带「第」字，界面又拼了一次。现在统一显示。

## 交互改动

- **去掉底部「更多」，面板入口只留右上角 ☰**。原来底部「更多」和右上角 ☰ 打开的是同一个抽屉，抽屉标签条里还有自己的「更多」，同一个入口出现多处。现在底部只放 5 个行动（探索、修炼、突破、斗法、交流），抽屉「常用」改为主角、背包、地图、玉简、人物、机遇，其余收进「其他」。灵宠、绝色榜等现在需点 ☰ 再展开「其他」。
- **叙事不再自动滚到最底**。发出行动后画面最多跟到你那句话的顶部，长回复从开头读起；你一旦自己滚动就停止跟随；离底部较远时右下角出现「↓ 回到最新」。进入游戏、载入存档时停在最近一条回复的开头。去掉了流式输出时的平滑滚动动画。
- **立绘可放大**。绝色榜、道侣、人物页点卡片或头像，弹出完整立绘（按原比例不裁切）加该角色的全部字段；点图可放大到 2.2 倍并拖动查看。灵宠页头像是固定图标，没有立绘，未做放大。
- **游戏中可回主菜单**。顶栏新增 ⌂ 按钮（手机、平板都有）；安卓返回键在没有弹层可收时回主菜单，主菜单上再连按两次才退出。回主菜单前会先把待写存档落盘；这一回合还在演算时会提示稍等并留在原地。

## 验证（如实）

- 前端 215 项测试：212 通过、0 失败、3 跳过（需要真实渠道的集成测试）。
- Rust 41 项测试通过（新增 SHA-256 规整、「有哈希才启用镜像」2 项）；`cargo fmt --check` 干净。
- 国内镜像实测（2026-11）：`ghfast.top` 完整下载 33,674,864 字节约 4 秒，SHA-256 与官方一致；`gh-proxy.com` 可用但较慢。
- **未在真机 / 模拟器上验证**：本版的界面改动（底部栏、滚动跟随、「回到最新」按钮、立绘放大层、⌂ 按钮、返回键回主菜单）和新的应用内下载流程，只做了语法检查与单元测试，没有在设备上实际操作过。

## 已知边界（如实写明）

- 镜像是第三方服务，会失效或限流（实测 `ghproxy.net` 很慢，`mirror.ghproxy.com`、`github.moeyy.xyz`、`gh.llkk.cc` 不通，`gh.ddlc.top` 返回 429）。镜像失效时会自动回退到 GitHub 直连。镜像列表写在 `update.rs` 里，需要定期复测。
- **从 0.8.0 及更早版本升级时**，应用内更新仍是旧的下载逻辑，国内可能仍会失败；请用浏览器下载本版 APK 覆盖安装（签名与之前版本一致，存档保留）。装上本版之后，后续更新才会走镜像。
- 附件 `dyapp-0.9.0-universal.apk` 用 debug 证书签名，可侧载并原地升级；`-unsigned` 是 CI 原样产物，不要安装。正式分发请换自己的 keystore。
- 需要自己填凭据才能跑通：真实大模型渠道、GitHub 云同步。
