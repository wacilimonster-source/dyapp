# 道渊 0.7.0

> 这一版是「交互实测审查」的落地：三处真问题 + 一批点不中的按钮。
> 改动全在界面上，引擎与叙事逻辑一个字没动 —— 也就是说，**你按上一版存档继续玩即可**。

## 修复（三处真问题）

1. **平板横屏右栏收不起来**。点标题栏那个写着「收起右栏」的箭头，右栏纹丝不动（实测点完宽度还是 372px）；
   在右栏标题上往下滑也一样 —— 这两个入口都在执行"展开"。修好后收起右栏，**正文从 566px 变成 760px**
   （行宽 552px ≈ 34 字/行），收起后点左栏任意图标即唤回。
2. **行动栏被「交流」挤变形**。上一版加了「斗法」，但底座的格子模板还是"4 个主行动"，于是「交流」被挤进
   52px 的窄格（其他四个 117px）、「更多」掉到第二行、右侧 4/5 空着。现在五个主行动等分一行，
   **操作区 228 → 175px，正文可视 524 → 572px**。
3. **1024×768 平板左栏装不下 16 个入口**。左栏内容 1013px 要塞进 768px，「模型 / 同步 / 设置 / 主菜单」
   全在首屏之外，而且看不出还能滑 —— 偏偏这几个是刚装机最先要找的。现在
   **「存档 / 模型 / 同步 / 设置 / 主菜单」五项钉在左栏底部常驻可见**，中间那段可滚，
   矮屏按钮压到 48px（安卓触控下限）。实测：底部 5 项全在，中段 8/11 可见，只剩「地图 / 图鉴 / 成就」
   需要滚动 —— 这三个都是"看"的入口，不是行动。

## 修复（触控目标统一到 44px）

手机上原有六类可点元素小于 44px：菜单键 38、行动建议胶囊 35、抽屉 tab 34、
设置页「小/中/大」字号按钮 **15×24**、气运库与模型点选里的「选」按钮 **52×30**、弹层关闭键 34。
现在统一到 44px（游戏界面内"小于 40px 的可点元素"命中数：3 → 0）。
代价如实说：抽屉里 tab 条从 91px 长到 111px（展开「更多」时 212px），面板正文区相应少一点。

顺带修掉一个连带问题：tab 从 34 抬到 44px 后，tab 条原本的高度上限会把展开「更多」的**第 4 行裁掉，
而被裁的恰好是「存档 / 模型 / 同步 / 设置」**，上限已跟着放大（实测「被裁：无」）。

## 变化（不是修 bug）

- **手机端绝色榜改三列**。上一版立绘让每张卡 373px 高、两列一屏只看 5 张；改三列后立绘正好是 2:3、
  不裁切，单卡 316px、每行 3 张。实测 5 张卡从 1.9 屏降到 1.1 屏，**按满 20 位折算 5.9 屏 → 3.3 屏**。
  立绘仍然是默认显示（没有改成"点开才加载"）。
- **新档主角面板的 容貌 / 身形 / 衣着** 由模型在首回合写入，之前是三行空标签（看着像坏了），
  现在空值显示「未定」。

## 量完之后决定不改的一处

气运创角那一步，我原先估"一屏 20 张候选要长滑"。实测只要 **2.4 屏**（候选 10 张、描述中位 63 字），
而描述原文正是选气运的依据 —— 折成摘要反而要逐条点开，所以保持原样。

## 已知边界（如实写明）

- **矮屏平板的左栏中段仍要滚动**（地图 / 图鉴 / 成就三项）：16 个入口在 768px 高度上无法同时以可点尺寸排下，
  钉住 5 个配置入口是取舍结果。如果你更想常驻的是「背包」，告诉我换。
- **软键盘弹出后输入框是否被遮**、以及动效/连点手感，无头浏览器测不了，仍需真机点一次。
  上一版（0.6.0）遗留的"应用内下载并安装 APK"也还没在真机上走过一遍。
- 立绘仍是热链卡作者的图床：链接随时可能成片失效，失效时自动退回名字首字（不会出现破图）。
