# 道渊 0.2.0

> 安卓手机 / 平板 + Windows 桌面。这一版把上一批缺陷修完，并接入了另一条工作线的功能。

## 新增

- **成就系统**：全部由引擎从状态判定，不依赖模型（境界、道侣、机遇、灵宠、气运各有对应条目），解锁记录写在存档里。
- **往昔回顾**：长局里超出提示词预算的更早回合，会被压成"时间 · 地点 + 正文开头"的摘要注入上下文，模型不再"忘了你去过哪、见过谁"。零额外模型调用。
- **存档缩略图**：存档列表带一眼可认的进度缩略图（旧档缺省为空，不影响读取）。
- **创角规则下沉到引擎**：出身加成、初始灵石、道侣建档、真·气运抽取都变成引擎里的确定性规则，可单测、可用固定随机源复现。
- **面板**：新增「成就」。

## 修复

- **存档写入改为整体换盘**：四个文件先在临时目录写全，再整体替换。进程在写入中途被杀（后台回收、掉电）只会得到"上一版"或"这一版"，不会出现"状态是新的、叙事流还是旧的"这种半截存档；换盘中断会在下次读写时自动回滚到上一版。
- **强制推送先备份远端**：覆盖远端前把远端那一版下载到存档目录的 `remote-backup-<时间戳>/`，不会无声抹掉另一台设备的进度。
- **存档列表不再出现空目录与写盘残骸**（`.tmp-writing` / `.old-backup` 一律过滤）。
- **玉简面板空数据崩溃**：创角时不选道侣（走「天道自定」）会让玉简为空，原先打开玉简面板或发信会抛异常并连带整个侧栏打不开；现在显示空状态提示。
- **密钥相关两处收紧**：模型配置里留空不再清空已存的 Key（清空必须走显式操作）；出网/入库前的敏感字段清洗增加了"包含名"匹配（`accessToken`、`openai_api_key`、`clientSecret` 这类变体原先会漏）。
- **鉴权头构造失败会明确报错**：Key 里混进换行/控制符时，原先静默不发鉴权头、只报一个莫名的 401。
- 依赖清理（移除未使用的 `uuid`，`tokio` 移入 `dev-dependencies`）。

## 工程

- CI 增加：非 Windows 平台的编译检查会真正跑起来（此前一条只在 Linux 上暴露的编译错误没被拦住）。
- 新增手动触发的产物构建工作流（Windows 安装包 + 安卓 APK）。
- 测试规模：前端 161 项、Rust 26 项、30 个文件的真 ESM 解析检查。
