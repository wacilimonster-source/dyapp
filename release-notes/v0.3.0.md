# 道渊 0.3.0

> 图标重做 + 模型配置改成点选 + 修掉桌面版「面板切不过去」这条死路。

## 新增

- **应用图标重做**：从"一个金色『渊』字加一圈细线"换成**阴阳双鲤绕渊眼、上方悬一剑**的徽标，配色与应用内同源（墨蓝 `#0d1220` / 鎏金 `#d4af37` / 紫 `#c58aff`）。安卓与 Windows 由同一张母图生成，两端一致：桌面 `icon.ico` 含 16/24/32/48/64/256 六档，安卓五档 mipmap 全部重出，并补上自适应图标（圆形与圆角两种遮罩都实测过，背景色改为应用墨蓝而不是默认白）。
- **模型列表点选，不用手输**：填好接口地址与 API Key 后自动向渠道拉 `/models`，弹「选择模型」框，点模型名右侧的「叙事」或「裁决」即填入对应输入框。
  - 进「模型」页会自动拉一次（本机已存 Key 或该渠道免 Key 时）；按「保存」后自动重拉；手动「测试 · 拉取模型」保留，成功即直接弹选择框。
  - 换接口地址会自动重拉；列表超过 60 个时选择框只列前 60，其余仍可手输。
  - 已实测渠道：opencodego 的 `…/zen/go/v1/models` 返回 38 个模型，格式为 OpenAI 兼容的 `data[].id`。

## 修复

- **桌面 / 平板版式下侧栏面板点不到**：顶部 tab 条原先强制单行横向滚动，而侧栏只有 372px 宽，常用 6 项实际需要 495px —— 第 5 个之后的面板（含「模型」「同步」「设置」）全被裁在框外，而 **Windows 的鼠标滚轮不驱动横向滚动**，等于这些面板在 exe 里根本点不到（浏览器能拖滚动条，所以之前没暴露）。现在：
  - tab 条改为**换行显示**，超过 3 行才纵向滚动（滚轮可用）；
  - 切换面板时自动把当前项带进视野；
  - 从主菜单直达「设置」这类收在「更多」里的面板时，自动展开「更多」组，不再出现"你在一页却看不到这页的标签"。

## 工程

- **发版链路新增 Windows 任务**：打 tag 后自动构建 NSIS 安装包并挂到同一个 Release，附件名 `dyapp-<版本>-windows-x64-setup.exe`（中文产物名一律改成纯 ASCII，方便下载与脚本处理）。与安卓任务一样标了"产物失败不阻塞发版"。
- **安卓 `versionCode` 1 → 2**：本版 APK 可以原地覆盖升级，不用先卸载。

## 下载哪个

| 附件 | 说明 |
|---|---|
| `dyapp-0.3.0-windows-x64-setup.exe` | **Windows 桌面版安装包**（NSIS，x64，装完自带新图标） |
| `dyapp-0.3.0-universal.apk` | **已用 debug 证书签好，可直接侧载安装**（通用包：`arm64-v8a` / `armeabi-v7a` / `x86` / `x86_64`，minSdk 26，versionCode 2 可覆盖升级）。签名者指纹与之前几版一致（同一把 `~/.android/debug.keystore`） |
| `dyapp-0.3.0-universal-unsigned.apk` | CI 的原样产物（未签名）。要自己签就用它，步骤见 `docs/03-应用架构与实现.md` 第 7.3 节（`zipalign` + `apksigner`） |
| `dyapp-prototype-v0.3.0.zip` | 前端静态资源（零依赖，起个静态服务就能在浏览器里跑） |

正式对外分发请换自己的 keystore 重新签：CI 不持有签名材料是**有意的**——keystore 不进仓库。

## 已知边界（如实写明）

- **多端同步仍要手填仓库与令牌**：「自动用本项目仓库 + 存档加密后再上传」这条已确认要做，但**未在本版实现**（等两个决定：存档放哪个仓库、加密口令怎么给）。
- **opencodego 选中模型后的真实对话需要你自己的 Key 实测**：本版能验证到"接口返回 38 个模型 + 前端点选回填正确"，带 `x-opencode-session` 头的端到端对话我这边没有 Key，验不了。
- 图标是 AI 绘制的插画风徽标，细节（剑、云纹）在 16px 一档会糊成一团色块；48px 起轮廓清楚。
- 测试规模：前端 158 项通过（另有 3 项需要真实 Key 的联调用例默认跳过）、Rust 侧见 CI、30 个文件的真 ESM 解析检查通过。
