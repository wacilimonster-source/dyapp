# 道渊 0.4.0

> 这一版全是"配置和同步不再需要你手动搬数据"：更新在应用内点一下就装好，存档出网前先加密。

## 新增

- **应用内直接下载并安装更新**（设置 → 版本与更新，发现新版后出现按钮）：
  - **安卓**：下载 Release 里那个已签名的通用 APK，下完自动拉起系统安装器。第一次会要你允许"安装未知应用"，在弹出的页面里点一次即可。下载过程显示实时进度（已下 / 共多少 MB）。
  - **Windows**：下载 `*-windows-x64-setup.exe` 到本机的应用目录，下完自动启动安装包。
  - 失败时给可读原因 + 「重试」，并且仍然保留「全部版本」入口可以手动下载。
- **同步存档出网前一律加密**：
  - 新增一项**同步口令**（自己定一句，只存本机）。存档在离开本机前用「口令派生的密钥」加密，GitHub 上只存密文（文件名带 `.enc`）。
  - 本机读写的仍是明文四件套，引擎照常直接读；加密只发生在"要上传"那一层。
  - **口令忘了就没有任何找回通道**——远端只剩解不开的密文。换设备要输入同一个口令。
  - 改口令的正确顺序：先用旧口令把远端拉下来 → 存新口令 → 再推一次。
- **同步不再要你手填仓库**：默认就用本项目自己的仓库（`wacilimonster-source/dyapp`）的 `saves/` 目录。想换再填 `owner/repo`。之所以敢用公开仓库，是因为上面那条加密。

## 修复

- **更新附件会挑中"装了被系统拒绝"的那个包**：原先取 Release 里第一个 `.apk`，而附件同时有已签名和未签名两份，未签名那份安卓根本装不上。现在按"排除 unsigned"挑，并按设备挑对应平台的包（安卓挑 APK、Windows 挑 setup.exe）。
- **自动推送会在没配齐时白报错**：没设同步口令时以前会每次存档都记一条"推送失败"。现在和没配令牌一样静默跳过——明文绝不能出网，这种推送注定失败。

## 工程

- 下载并执行安装包这条链路做了五道约束，都写在 `app/src-tauri/src/update.rs` 并配单测：只允许 https、域名白名单、**跟随重定向之后再查一次域名**、文件名只取 URL 末段且收窄字符集、只允许安装落在本应用暂存目录内的 `.apk`/`.exe`。
- 加密实现 `app/src-tauri/src/envelope.rs`：口令 → PBKDF2-HMAC-SHA256（31 万轮）→ ChaCha20-Poly1305。盐与"口令对不对"的校验放在远端 `saves/.keycheck`，所以一次同步只派生一次密钥；nonce 由内容决定而非随机，否则"内容没变就跳过上传"会退化成每次全量重传。
- 测试规模：前端 158 项、Rust 38 项、30 个文件的真 ESM 解析检查。
- CI 的"前后端命令名一致性"门禁补上 `update_` 前缀（不补会把新命令误报成未注册）。

## 已知边界（如实写明）

- **本版发出来后，你自己装的 0.3.0 还看不到"直接下载"按钮**——那个按钮是 0.4.0 才有的功能。也就是说这条链路要等**下一次**发版（0.4.x → 0.4.y）才能在真机上被点到。本版我能验证到的程度：下载/安装的**决策与错误处理**在假壳里跑通、URL 与文件名校验有单测、安卓目标能编译；**安装器是否真弹出、真实仓库上的加密推送/拉取往返，需要你在真机与带令牌的环境点一次**。
- 同步口令与 API Key 存在同一个本机密钥文件里，受同一层保护（Windows 上用系统账号绑定加密）。它不会进存档、不会被同步、不会出现在导出包里。
- 逐回合合并仍然没有做：两端各自推进后是"整档后来者胜"，冲突时靠备份目录手工找回。
