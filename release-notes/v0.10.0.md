# 道渊 0.10.0

> 安卓手机 / 平板。主题：**对话里打起来，也要有斗法判定**。

## 修复

- **对话里的战斗不触发斗法判定**。原来只有点底部「斗法」按钮才会弹出「道争·判定」面板；在对话里打起来，引擎虽然掷了骰，面板却不出现。现在只要本回合有斗法结果，不管是按钮还是自由输入，都会先弹判定面板，点「承认结果」后再显示正文。
- **更新包不再出现「只有未签名 APK」**。v0.9.0 的 Release 附件里只有 `-unsigned.apk`，客户端挑附件时会避开它，导致应用内更新找不到可装的包。本版起 APK 在本机构建并签名后再上传，附件只有已签名的 `dyapp-0.10.0-universal.apk`。

## 新增

- **叙事里爆发战斗时由引擎判定**。裁决环节新增 `combat` 字段：正文里有人动手、双方已经或即将交手时，裁决器标出对手名；争吵、威胁、单纯对峙不算。标出后引擎按境界差、道心、灵力掷骰，随后让模型接着写战斗经过，伤势与修为变化照常落地。
  - 叙事提示里新增一条：战斗爆发时只写到双方交手的一瞬，不写胜负。
  - 对手如果在人物表里，按他的境界算；不在人物表里，名字用裁决器给的，境界按危机程度估算。
  - 触发斗法的回合会**多调用一次模型**来续写战斗，多花一点时间和 token。
- **战斗词表扩充**：补了「交手、偷袭、突袭、反击、祭出、拼杀、杀了、斩了、打败、教训」。自由输入里写这些词会直接走引擎斗法。

## 交互改动

- **顶部六维条重做**。原来是一根 8px 的无字彩条，六段按数值占比分宽，看不出每段代表什么。现在默认只显示「生命 / 灵力 / 修为」三条带名字的细条，生命或灵力低于 30 时名字变红；右侧「六维 ▾」点一下展开全部六维，展开后变成「收起 ▴」。

## 验证（如实）

- 前端 217 项测试：214 通过、0 失败、3 跳过（需要真实渠道的集成测试）。新增 2 项覆盖「裁决器标出 combat → 引擎判定 + 续写 + 伤势落地」和「combat 为 null → 不触发、不多调一次模型」。
- Rust 41 项测试通过；`cargo fmt --check` 干净。
- 本版 APK 在本机构建，用与 0.8.0 / 0.9.0 同一个 debug 证书签名；`apksigner verify` 通过，证书 SHA-256 指纹为 `e436a586…274f06`，与旧版一致，可原地覆盖安装、存档保留。
- **未在真机 / 模拟器上验证**：六维条的新样式、判定面板在自由输入里的弹出，以及「叙事触发斗法」的整条链路，只做了单元测试与语法检查，没有用真实大模型跑过。

## 已知边界（如实写明）

- **模型不一定遵守「写到交手瞬间为止」**。如果模型在第一段正文里就写出了胜负，会和随后的引擎判定矛盾；这一点需要用真实模型多试几轮才知道。续写失败时会保留引擎判定和原正文，并在日志里记一条。
- **裁决器漏标 `combat` 时不会触发**。战斗词表只对玩家自己输入的文字生效；模型写的剧情里即使打起来了，裁决器没标就不判定。
- **从 0.8.0 及更早版本升级时**，应用内更新仍是旧的下载逻辑，国内可能仍会失败；请用浏览器下载本版 APK 覆盖安装（签名与之前版本一致）。
- **从 0.9.0 升级**：0.9.0 的 Release 里没有已签名 APK，应用内更新在 0.9.0 上找不到可装的包，同样请手动下载本版 APK 覆盖安装。
- APK 用 debug 证书签名，可侧载并原地升级；正式分发请换自己的 keystore（换证书后旧版用户必须卸载重装，存档会丢，需提前导出）。
- 需要自己填凭据才能跑通：真实大模型渠道、GitHub 云同步。
