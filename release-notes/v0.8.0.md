# 道渊 0.8.0

> 安卓手机 / 平板 + Windows 桌面。主题：**看得见、上得手、名实相符**。

## 新增

- **玉简真回信**：传讯终于真的由 AI 回信（此前是三条写死台词轮着冒充，发第二条就穿帮）。带联系人卡与最近往来，回信有口吻；发送失败会明说"传讯未达"并把原文放回输入框，绝不假装发出去了。
- **每回合账单**：叙事气泡下多了一行 `≈1.3k tok（入 1.2k / 出 56）· 1.1s · 缓存命中 32%`——一回合花多少 token、等多久，从此可见。「设置 → 用量」有累计 / 今日 / 缓存命中 / 清空。渠道不返回用量时只计次数与耗时，不编数字。
- **首启三步向导**：全新安装会带着配渠道：①选渠道（内置 opencodego / OpenAI / Ollama / 自定义）②地址与 Key ③模型点选 + **真测连**（真发一条 1-token 对话——拉到模型列表不等于能对话，中转渠道常按路由分开鉴权）。401 / 超时 / 404 / 限流各给一句人话。可跳过，「设置 → 重跑配置向导」随时再来。
- **安卓返回键**：按返回不再直接退出——依次收起弹层 → 抽屉 → 全屏页，最后"再按一次返回键退出"。判定层按返回等同"承认结果"，不会丢回合。
- **器灵台词**：卡里现成的台词终于启用——突破时低语一句、闲置两分钟低语一次（每局一次）、时间线回看里作旁注。纯引擎随机，零模型调用。

## 改进

- 叙事回合与玉简传讯统一走"渠道返回 usage 才计入"的口径，跨会话累计（本机 localStorage，留 90 天明细 / 20 档分档）。

## 验证（如实）

- 前端 215 项测试 0 失败（新增账单格式 / 玉简提示词 / 测连错误分类 / 器灵抽取 12 项回归），Rust 40 项（新增 usage 抽取 2 项），35 文件真 ESM 解析。
- 真机（Pixel 6 / Android 14 / x86_64）用本机 mock 渠道全链路验证：向导自动触发 → 三步 → 测连"连通了（首字 0.5s）"→ 玉简流式回信**并落盘**（state.json 里可见往来记录）→ 账单数字与 mock 给的用量精确吻合 → 返回键逐层收起、双按退出、重启不再弹向导。
- 一处已知小瑕疵：向导第③步的模型芯片样式偏素（借用了 tab 样式），功能不受影响，0.9 顺手修。

## 已知边界（如实写明）

- **需要你自己填凭据才能跑通**：真实大模型渠道、GitHub 云同步。0.8.0 的真机验证用的是本机 mock 渠道（不消耗你的 Key）；真实渠道请用向导的「测连」确认。
- 附件 `dyapp-0.8.0-universal.apk` 已用 debug 证书签好可直接侧载（签名者与之前版本一致，可原地升级）；`-unsigned` 是 CI 原样产物。正式分发请换自己的 keystore（CI 不持有签名材料是有意的：keystore 不入库）。
- 向量召回未做（BM25 + 规则重排）；安卓返回键的"无层可收"场景之外不会强杀进程，交给系统。
