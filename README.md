# dy · 《道渊》独立版

把酒馆角色卡 **《道渊》v5.3** 重做成一个 **AI 驱动的修仙独立游戏 APP** 的设计工作区。

> 一句话定位：**引擎管账本与规则，模型管演出与自由剧情。**
> 现状：这份工作区目前只包含**产品设计方案**（尚未开始编码）。

---

## 这是什么

《道渊》现在是一张"提示词里的小游戏引擎"：20 万字世界书、18.5 万字创角界面、20 万字状态栏模板、319 条设定、MVU+Zod 变量系统、动态遭遇、三重人格审查——它已经是个游戏引擎，只是被迫跑在聊天框里，靠正则替换当渲染层、靠模型自觉当状态机。

独立版要做的是：把状态与规则搬进本地引擎、把世界书检索换成按需注入、把界面换成原生渲染、把 AI 对话保留为内核，外面套一层独立游戏的壳（菜单/创角/存档/图鉴/演出）。

### `prototype/` 说明（安卓手机 / 平板）

| 文件 | 内容 |
|---|---|
| `index.html` | 入口，可直接用安卓浏览器打开或包进 WebView |
| `styles.css` | 版式由 `#app[data-layout="phone\|tablet"]` 驱动；含安全区与 44dp 触控尺寸 |
| `data.js` | 假数据，结构对齐 `GameState`，名称与数值取自卡内真实设定 |
| `app.js` | 导航、创角向导、HUD、叙事流、11 个面板、判定演出 |
| `update.js` | 检查更新模块：读 GitHub Releases、语义化版本比较、离线降级 |

运行：在 `prototype/` 目录起静态服务（如 `python -m http.server 8777`），浏览器访问 `http://127.0.0.1:8777/`。
真机按屏幕宽度自动判定版式；桌面预览用右下角「手机 / 平板」开关切换。

- 远端：<https://github.com/wacilimonster-source/dyapp>（公开）
